## 4. Two-week presentation MVP (priority)

**Window:** ~2 weeks (sprints P0 and P1)  
**Intent:** Ship a working product slice suitable for presentation, with production hardening deferred.

**Required end-to-end path**
```text
Auth → server quote → persisted intent → USDT pay (Polygon/Base testnet)
  → deposit detect/credit → MoMo sandbox disbursement → paid → receipt
```

Plus a thin admin surface on the same data (transactions, FX, treasury).

**In scope**
- Server-trusted quotes and persisted payment intents  
- Real testnet deposit detection  
- Real MoMo sandbox payout  
- Receipt with real references  
- Surgical landing updates (chain copy, calculator wiring)  
- Preview deploy + rehearsal  

**Out of scope for this window**
- Mainnet / Rwanda production MoMo  
- Full security hardening and observability suite  
- Deep GraphQL indexer work beyond a working detect path  
- Landing redesign  

**Success criteria:** Cold, repeatable demo on a deployed URL completing the path above, with admin able to view the same transaction and adjust FX.

| Period | Sprints | Theme |
|--------|---------|--------|
| Month 1 | S1–S4 | Foundation, auth, quotes, pay UI, chain detection |

Safe defaults are documented for open product decisions (confirmations, matching, caps) so implementation is not blocked while those decisions finalize.
